# 2026-07-17 博客功能讨论与更新日志功能实现

## 讨论内容
- 与用户（软工学生）讨论博客应有的功能分三层：基础体验（Layer 1）、展示力（Layer 2）、工程力（Layer 3）
- 用户提出新增"更新日志"功能需求
- 用户授权自主优化博客

## 已实现

### 第一次推送：更新日志
1. **`posts/changelog.json`** — 结构化变更日志数据，支持 date/type/description/slug
2. **`posts/index.json`** — 每篇文章新增 `updatedAt` 字段，补全了遗漏的 3 篇早期文章条目
3. **更新日志页面** — 新增 `#/changelog` 路由，时间线样式渲染，按月份分组，彩色标签区分变更类型（初始化/新增/修复/批量导入/更新/优化）
4. **导航栏** — 增加"更新日志"入口链接
5. **`scripts/build-changelog.js`** — 自动构建脚本，通过对比文件修改时间与 index.json 日期来增量追加 changelog 条目
6. **修复 BOM 问题** — 去除 index.json 的 UTF-8 BOM 头，确保 Node.js JSON 解析兼容

### 第二次推送：代码高亮 + TOC + 复制 + 信息栏（自主优化）
1. **代码语法高亮** — 集成 highlight.js，light/dark 双主题随暗色模式自动切换
2. **代码复制按钮** — 每个代码块右上角有复制按钮，点击后显示"已复制"
3. **语言标签** — 代码块上方显示语言名（python、java、cpp 等）
4. **文章目录 TOC** — 自动从 h2/h3 生成导航链接，IntersectionObserver 实现滚动高亮
5. **文章信息栏** — `.post-meta-bar` 样式完整，展示了 updatedAt（更新日期）
6. **删除重复日期** — 所有 Markdown 文件中与 meta-bar 重复的 `**YYYY-MM-DD**` 行已删除

### 第三次推送：修复 TOC 锚点 + 改为左侧可折叠侧边栏（用户反馈）
1. **修复锚点跳转** — TOC 点击不再被 hash 路由拦截，改用 scrollIntoView 平滑滚动
2. **左侧可折叠侧边栏** — 折叠时显示 📖 小浮标，展开后在文章左侧展示目录列表
3. **IntersectionObserver 滚动高亮** — 滚动时自动高亮当前章节对应的目录项
4. **移动端适配** — 移动端自动变为顶部抽屉
