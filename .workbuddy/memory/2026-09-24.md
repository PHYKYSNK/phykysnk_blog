## 修改标签功能 + Python 标签修正

### 背景
用户前几天新增的 2 篇 Python 文章标签误写为 "Y"，需修正；并要求在管理面板「编辑文章」中加入修改标签能力。

### 关键事实（项目约定）
- **标签只存在 `posts/index.json` 的 `tags` 数组里**，Markdown 正文文件不存标签。改标签 = 改 index.json。
- 前端标签点击是**纯客户端过滤**，不跳路由：`data-tag` 属性 → `currentTag` 全局变量 → `renderPosts()` 过滤。

### 已完成
1. **数据修正**：`posts/index.json` 中 `Python复学笔记`、`Python基础语法速查` 的 tags 由 `["Y"]` 改为 `["Python"]`。
2. **`scripts/new-post.js` 升级**：
   - 新增 `tagMode()` 快捷入口（`--tag`，菜单 [7]），只改标签不开编辑器。
   - `editMode()` 重写：选中文章后先问「改正文 / 改标签 / 两者都改」。
   - 抽出可复用函数：`collectAllTags`、`printPostPicker`、`parseTagInput`、`editTagsFlow`、`openInEditorAndWait`、`gitCommitPush`。
   - 菜单从 7 项扩到 8 项（[6] 编辑文章（正文/标签）、[7] 修改标签、[8] 退出）。
   - 文章列表展示当前标签，标签输入支持中英文逗号，留空可清空标签。
3. 已 `git push`（commit 63cd1e8）。
