## 文章内下载按钮 + 发布「随地大小粘」

### 背景
用户想把一个 zip 便携包发布到博客供他人下载，形式为「按钮 + 显示文件大小」。

### 新增能力：下载按钮
**语法**（写在 md 里）：
```
[按钮文字](assets/files/xxx.zip){download size="11.99 MB" note="Windows · 解压即用"}
```
**实现**：
- `scripts/main.js` 新增 `enhanceDownloadLinks()`，在 `showPost()` 里 `marked.parse()` 之后、`highlightCodeBlocks()` 之前调用。
- 关键坑：**marked 会把 `{...}` 里的双引号转义成 `&quot;`**，正则必须写成
  `size\s*=\s*(?:"|&quot;)(.*?)(?:"|&quot;)`，并配 `unescapeHTML()` 还原。
- 双层处理：① 显式 `{download ...}` 语法；② 兜底——站内 `.zip/.exe/.pdf` 等后缀链接自动转按钮。
- 生成的 `<a class="download-btn" download>` 带 `download` 属性，强制下载而非浏览器预览。
- `styles/main.css` 新增 `.download-btn` 系列样式（暖色调卡片 + 左侧 accent 竖条 + CSS 画的下载箭头图标）。
