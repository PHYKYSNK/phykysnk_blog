# 2026-10-08

## 新增舒尔特方格训练页 + 重构视图切换

### 背景
用户想在博客里加舒尔特方格（Schulte Grid），主要用于**手机端注意力训练**。先给方案商量后开工。

### 决策（用户确认）
- 功能范围：**基础版** —— 5×5 固定、计时、错误计数，**不做**历史记录
- 入口：**导航栏**加「训练」
- 顺手**重构视图切换**

### 关键改动
1. **视图切换重构**（`scripts/main.js`）
   - 原来 4 个 `show*()` 各自手写枚举所有视图的 hidden 切换，加第 5 个视图要改 4 处、易漏。
   - 改为 `var views = {home, post, about, changelog, training}` + `showView(name)`，用 `classList.toggle('hidden', key !== name)` 统一处理。
   - **以后新增页面只需在 views 里登记一项 + 加路由分支。**

2. **舒尔特方格**（`scripts/main.js`）
   - 常量 `SCHULTE_SIZE = 5` / `SCHULTE_TOTAL = 25`，改尺寸只需改一处。
   - `shuffle()` 用 **Fisher-Yates**（不用 `sort(()=>Math.random()-0.5)`，分布不均）。
   - 计时用 `performance.now()`（单调时钟），`setInterval(tick, 50)` 刷新显示。
   - 状态对象 `schulte = {next, errors, startAt, timerId, running, elapsed}`。
   - 点对 → 加 `.done`（变淡 + `pointer-events:none`）；点错 → 加 `.wrong` 300ms 后移除 + errors++。
   - **`renderPlaceholderGrid()`**：未开始时渲染 25 个占位格，避免遮罩层（absolute inset:0）因父容器无高度而塌陷。
   - `resetSchulte()` 每次进入训练页都调用，清理旧 timer 防止泄漏。

3. **`index.html`**：新增 `#training-view` 容器（统计栏 + 方格 + 遮罩）；导航栏加「训练」链接。

4. **`styles/main.css`**：`.schulte-*` 系列样式，移动优先。
   - `touch-action: manipulation`（防双击缩放）、`user-select: none`（防长按选中）、`-webkit-tap-highlight-color: transparent`。
   - `.schulte-grid` 用 `aspect-ratio: 1/1` + `grid-template-rows: repeat(5,1fr)` 保证方格区恒为正方形。
   - 桌面端 `.schulte-board-wrap { max-width: 480px }` 居中，避免鼠标移动距离过长。
   - 错误态 `#e6b8a4`（暖色），暗色模式单独覆盖。

### 验证方式（重要，可复用）
环境无 agent-browser、无 npm，**自建最小 DOM 桩**在 Node 里真实执行 `main.js`：
- 桩实现 Element（classList/appendChild/addEventListener/innerHTML/textContent/setAttribute）、document、window、localStorage、fetch、performance。
- 用 `new Function(...)` 注入桩后执行 main.js 源码，捕获 `DOMContentLoaded` 回调并触发。
- 再手动派发 hashchange + click 事件，驱动完整流程。
- 结果：**28 项断言全部通过**（含视图互斥，验证了重构正确）。
- 另做 Fisher-Yates 无偏性抽样（20 万次，625 个位置-数字组合，均值 8000、σ86.7，最大偏离 3.34%，在 4σ 内）。
- 测试文件保留在 `tests/schulte.test.js`（该目录会被 Cloudflare 一并部署，无敏感信息）。

### 备注
- 本次未做历史记录（用户明确不要）。若以后要加，方案是 localStorage，跨设备则需接 WorkBuddy 云服务。
- 舒尔特方格是训练工具而非测评工具，不宜强调「及格秒数」，应以用户自身纵向进步为指标。
