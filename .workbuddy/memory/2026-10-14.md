## ⚠️ 环境坑：git 提交疑似存在「已提交但报 nothing to commit」

本次与上次（背景更换）**连续两次**出现同一现象：执行 `git add xxx && git commit -m "..."` 后，
命令输出 `On branch main / nothing to commit, working tree clean`（即 commit 命令似乎无事可做），
但 `git log` 里**目标 commit 实际已经生成**、工作区干净。

**后果**：若用 `&&` 串联后续的 `git push`，会因 commit「退出码非 0」而**短路跳过 push**，
表现为「改了文件、commit 也有了，但远端一直不更新」——正是本次「上次换背景没生效」的真实原因。

**对策**：
1. 推送不要用 `&&` 串联，改用 `;`；或
2. 提交后先 `git log origin/main..HEAD --oneline` 确认，再单独执行 `git push origin main`。
