# 2026-07-19 添加 new-post.js 交互式写文章工具

## 新增
- `scripts/new-post.js` — 交互式 CLI 工具，三种模式：
  1. **交互模式**：`node scripts/new-post.js` 一步步引导输入
  2. **快速模式**：`node scripts/new-post.js "标题" --tags "标签" --push`
  3. **扫描模式**：`node scripts/new-post.js --scan` 检测未注册文件并补注册
- 自动：创建 `.md` 文件 + 更新 `index.json` + 更新 `changelog.json` + 可选 git commit/push
