# Markdown 基础语法速记


---

## 标题

```markdown
# 一级  ## 二级  ### 三级
```

## 强调

**粗体**  *斜体*  ~~删除线~~

## 代码

行内：`代码`
代码块：三个反引号 + 语言名

## 链接与图片

```markdown
[文字](链接)
![alt](图片.png)
```

## 列表

```markdown
- 无序
1. 有序
```

## 引用

```markdown
> 引用
> > 嵌套引用
```

## 表格

```markdown
| 左 | 中 | 右 |
|:---|:---:|---:|
```

## 任务列表

```markdown
- [ ] 未完成
- [x] 已完成
```

## 转义

\* \# \` 显示符号本身
